# 快递运费计价算法参考

## 核心概念

### 计费重量 (Chargeable Weight)

快递计费采用 **实际重量** 与 **体积重量** 取大值的原则：

```
体积重量(kg) = 长(cm) × 宽(cm) × 高(cm) / 体积系数
实际重量(kg) = 包裹总重
计费重量(kg) = MAX(实际重量, 体积重量)
```

**常用体积系数**：
| 快递类型 | 体积系数 | 说明 |
|----------|---------|------|
| 标快 (Standard Express) | 6000 | 标准空运体积换算 |
| 特快 (Express Plus) | 6000 | 同标快 |
| 特惠 (Economy) | 12000 | 陆运/慢件体积换算更宽松 |
| 重货专运 | 8000 | 介于标快和特惠之间 |

### 重量进位规则

计费重量向上取整：
- 不足 1kg 按 1kg 计算
- 常规包裹首重 1kg，续重按 0.5kg 或 1kg 进位
- 轻抛货（体积重量明显大于实际重量）按计费重量进位

## 定价模型

### 模型一：首重 + 续重 (阶梯定价)

最常见的快递定价方式：

```
总运费 = 首重价格 + (计费重量 - 首重) / 续重单位 * 续重单价
```

示例：首重 1kg 内 12 元，续重每 0.5kg 加 2 元，计费重量 3.2kg

```
首重费 = 12 元 (首1kg)
续重部分 = 3.2 - 1 = 2.2kg
续重计费单位 = CEIL(2.2 / 0.5) = 5 个 0.5kg
续重费 = 5 × 2 = 10 元
总基础运费 = 12 + 10 = 22 元
```

### 模型二：分区定价 (Zone-based)

适用于同城、省内、跨省、跨境等不同距离场景：

| 区域 | 首重(1kg) | 续重(元/0.5kg) | 说明 |
|------|----------|---------------|------|
| 同城 | 8 | 1 | 同一城市 |
| 省内 | 10 | 1.5 | 省内不同城市 |
| 经济圈 | 12 | 2 | 江浙沪皖 / 京津冀 / 珠三角 |
| 省外(一类) | 15 | 3 | 邻近省份 |
| 省外(二类) | 18 | 4 | 远距离省份 |
| 省外(三类) | 22 | 6 | 偏远地区(新疆/西藏/内蒙古等) |
| 港澳台 | 30 | 10 | 港澳台地区 |
| 国际 | 另议 | 另议 | 按目的国报价 |

### 模型三：分段累计 (Progressive Tier)

重量越大，超出部分的单价越低：

```
0 < W <= 50kg:   按标准单价
50 < W <= 100kg: 超出50kg部分 × 0.9
100 < W <= 500kg: 超出100kg部分 × 0.85
500 < W:  超出500kg部分 × 0.8
```

## 三大快递类型定价规则

### 1. 标快 (Standard Express, type=1)

- 时效：全国次日/隔日达
- 体积系数：6000
- 首重 1kg，续重以 0.5kg 为单位
- 支持保价（费率 0.5%，最低 1 元）
- 燃油附加费：基价 × 燃油费率（默认 0%）

### 2. 特快 (Express Plus, type=2)

- 时效：当日达/次晨达
- 体积系数：6000
- 首重 1kg，续重以 0.5kg 为单位
- 在标快基础上溢价 1.3-1.5 倍
- 保价费率 0.5%
- 专属服务费：基价 × 10%（如有）
- 燃油附加费：基价 × 燃油费率

### 3. 特惠 (Economy, type=3)

- 时效：3-5 天
- 体积系数：12000（体积要求更宽松）
- 首重 1kg，续重以 1kg 为单位
- 单价较标快低 30%-50%
- 保价费率 0.5%
- 通常不支持当日/次日达

## 附加费用

### 保价费 (Insurance Fee)

```
保价费率 = 0.5% (标准费率)
保价费 = 保价金额 × 保价费率
最低保价费 = 1.0 元 (不足1元按1元)
```

当 `insure_value = 0` 时，保价费为 0。

### 偏远地区附加费

偏远地区（如西藏/新疆/青海/内蒙古/甘肃）额外加收：

```
偏远附加费 = 基础运费 × 偏远系数 (通常 1.2-1.5)
```

### 特殊时段附加费

春节等高峰期可能加收：

```
高峰附加费 = 基础运费 × 高峰系数 (通常 1.1-1.3)
```

### 超长/超重附加费

- 单边超过 100cm：加收 10%-20%
- 单件超过 30kg：加收超重费

## 计费区域映射

### 中国省份区域分类

```
一类地区: 广东、江苏、浙江、上海、北京、天津
二类地区: 福建、山东、湖南、湖北、河南、河北、安徽、江西、广西、海南、重庆、四川、陕西、山西
三类地区（偏远）: 西藏、新疆、青海、内蒙古、甘肃、宁夏、云南、贵州、黑龙江、吉林、辽宁
```

### 同城判断规则

- 寄件城市 = 收件城市 → 同城
- 寄件省 = 收件省 → 省内
- 寄件省经济圈 = 收件省经济圈 → 经济圈内

## 完整运费计算公式

```
// Step 1: 计算体积重量
体积重量 = 长 × 宽 × 高 / 体积系数

// Step 2: 确定计费重量
计费重量 = CEIL(MAX(实际重量, 体积重量))

// Step 3: 查找区域价格表
首重价格表[快递类型][区域等级]
续重单价表[快递类型][区域等级]

// Step 4: 计算基础运费
if 计费重量 <= 1:
    基础运费 = 首重价格
else:
    续重 = 计费重量 - 1
    首重费 = 首重价格表[快递类型][区域]
    续重单元数 = CEIL(续重 / 续重单位)
    基础运费 = 首重费 + 续重单元数 × 续重单价

// Step 5: 计算附加费用
保价费 = IF(insure_value > 0, MAX(insure_value × 0.005, 1.0), 0)
附加费 = 基础运费 × (偏远系数 + 高峰系数 + 服务费系数)

// Step 6: 总费用
总价 = 基础运费 + 保价费 + 附加费
```
